# Filtrado de aguas grises

## Contexto

- Clima mediterráneo, veranos secos y calurosos.
- Ocupantes: 2 personas actualmente, con previsión de más en el futuro.
- Origen de las aguas grises: fregadero, lavadora, lavavajillas, duchas y grifos de lavabos.
- Se busca un sistema de filtrado natural (no químico/mecánico industrial).
- Sistema actual: pozo negro existente (no conectado a las aguas grises). Las grises actualmente desaguan por una tubería directamente al suelo sin tratamiento.

## Objetivo y criterio de éxito

- Reutilizar las aguas grises filtradas para riego.
- El agua tratada debe poder almacenarse durante períodos largos (semanas/meses) sin degradarse.
- Sistema de filtrado natural (biofiltración, humedales, etc.).
- Criterio de éxito principal: que el agua almacenada no genere malos olores.
- Destino del riego: frutales, huerto y jardín.

## Restricciones

- Presupuesto: sin definir todavía (fase de diseño/creación).
- Espacio: no es limitante, hay terreno de sobra.
- No se quiere un sistema prefabricado/comercial (caros y poco flexibles).
- Normativa: se obvia deliberadamente (no es una restricción para este diseño).

## Decisiones tomadas y exploraciones previas

- Descartado: sistemas prefabricados/comerciales de tratamiento de aguas grises (motivo: precio elevado y poca flexibilidad).
- Decisión: el sistema debe ser construido de forma artesanal/natural con materiales accesibles.
- Preferencia: enfoque ecológico/natural, pero abierto a incorporar tecnología puntual (ej: UV) si aporta valor.
- Sin preferencia cerrada por un tipo concreto de sistema — se deja abierto al consejo.

## Decisión concreta que necesitas

- Diseño completo de un sistema de filtrado natural de aguas grises: arquitectura, etapas, materiales, dimensionado.
- Que el consejo presente opciones y recomiende la más adecuada para el contexto (clima mediterráneo, almacenamiento prolongado).
